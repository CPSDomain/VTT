# Roadmap

What Tabletop has, what's coming next, and what's on the wish list. The order is a proposal: change it to match what the group needs most. Each version's details go in the [changelog](../CHANGELOG.md) when it ships.

Status: ✅ done · 🔨 in progress · 📋 planned · 💡 idea

## Done

| Version | What shipped |
| --- | --- |
| 0.1–0.2 | Shared grid map, tokens with owners, server-side dice, quick rolls, private rolls, nat 20/1 |
| 0.3 | Desktop apps (DM and Player), map builder, image maps, multiple maps with private prep |
| 0.4 | 69 props, token library (215 tokens + uploads), hidden tokens, map generators, Select tool for map pieces |
| 0.5 | Fog of war with Reveal room, brushes, and nothing hidden sent to players |
| 0.6 | Map generator v2: describe the map in words, many more settings, dungeon styles, wilderness kinds, building interiors, seeds |

## Next

### 0.7 — Combat 📋
- Initiative tracker: add tokens, roll or type initiative, turn order, next turn, round counter
- Whose turn it is highlighted on the map
- HP bars on tokens (DM chooses who sees exact numbers), temporary HP
- Conditions as markers on tokens (prone, poisoned, concentrating, and the rest of the standard set)

### 0.8 — Table tools 📋
- Ruler: measure distance in feet, with 5e diagonal rules
- Spell templates: cone, sphere, cube, line, cylinder, shown to everyone
- Ping: click to flash a spot for everyone ("over here!")
- Map labels and notes: DM-only notes, or labels everyone sees (room names, "Here be dragons")

### 0.9 — Bring your stuff 📋
- MapTool import: campaigns (`.cmpgn`) and maps (`.rpmap`), with maps, tokens and revealed fog. *Needs a sample file from the group.*
- Export and import single maps, to share between DMs or keep a library
- Restore from a backup inside the app

### 1.0 — Ready for anyone 📋
- Player passcodes, and the DM can remove a player
- Update check: the apps tell you when a new version is on GitHub
- Windows installer and code signing (no more SmartScreen warning)
- Automatic builds on GitHub when a version is tagged
- Linux and macOS builds

## Later 💡

- **Lighting and vision:** light sources, darkvision, line of sight through walls and doors
- **Handouts:** show an image or text to all players or one player
- **Chat and whispers** next to the roll log
- **Encounter builder:** SRD monsters with stat blocks, difficulty by party level, drop the encounter on the map
- **Adventure import** from the TaleSpire DM agent's output (maps, encounters, notes)
- **D&D Beyond link** on each player's token to open their character sheet
- **Music and ambience** controlled by the DM
- **AI map generation:** free-text descriptions read by Claude (needs an API key and internet), on top of the built-in description box
- **Tablet support:** touch controls for players on tablets
- **Multi-level maps:** floors linked by stairs
- **Weather and time-of-day** overlays
